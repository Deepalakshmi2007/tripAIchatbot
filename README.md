# ✈️ Trip AI Chatbot

## 📌 Project Overview

Trip AI Chatbot is an AI-powered travel assistant designed to help users plan their trips easily and quickly. The chatbot can understand user questions related to travel and provide useful information and suggestions.

## 🎯 Objectives

* Help users plan their trips.
* Provide travel-related information through an AI chatbot.
* Suggest destinations and travel ideas.
* Answer user questions in a simple conversational way.
* Make trip planning faster and easier.

## 🚀 Features

* 🤖 AI-powered chatbot
* 🗺️ Travel and destination assistance
* 💬 Natural language conversation
* 📍 Trip planning support
* 💡 Travel suggestions
* ⚡ Fast responses using an AI API

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML**
* **CSS**
* **JavaScript**
* **Groq API**
* **AI / Large Language Model**

## ⚙️ Installation

### 1. Clone or download the project

Download the project files to your computer.

### 2. Install required packages

Open the terminal inside the project folder and run:

```bash
pip install -r requirements.txt
```

### 3. Add your API Key

Add your Groq API key in the appropriate configuration/environment variable.

**Do not share your API key publicly or upload it to GitHub.**

### 4. Run the application

Run:

```bash
python app.py
```

### 5. Open the chatbot

Open the local URL shown in the terminal, usually:

```text
http://127.0.0.1:5000
```

## 💬 Example Questions

Users can ask questions such as:

* "Suggest a trip for 3 days."
* "What are the best places to visit in Tamil Nadu?"
* "Plan a budget trip."
* "What should I pack for my trip?"
* "Suggest places to visit with my friends."

## 🔒 Security

The API key should be stored securely using environment variables and should never be exposed in frontend code or uploaded to public repositories.
